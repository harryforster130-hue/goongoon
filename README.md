# NO CHOICE FC

A darkly satirical, fully static football career simulator.

You are a young disabled footballer trying to build a career from age 16 onward. You choose your position, train before matches, decide what to attempt during match moments, deal with transfers and contracts, survive media nonsense, and eventually retire.

The game is deliberately cynical about the football industry. It is **not** cynical about disability: the protagonist is treated as a capable person with a real football career, while clubs, media, sponsors, agents and corporate bureaucracy provide the jokes.

## Core gameplay loop

Each season contains **10 individual matchdays**:

1. **Training session** — choose a focus.
2. **Training outcome** — the selected focus has a potential stat profile, but success is chance-based.
3. **Match preview** — your position, fitness and opponent are shown.
4. **Live match moment** — choose what you attempt.
5. **Match simulation** — starts, team result, rating, goals, assists, clean sheets and injuries are calculated from stats plus seeded random rolls.
6. **Occasional club/media event** — transfers, sponsors, managers, journalists, ownership problems and other football-industry nonsense.
7. After 10 matches, the season is summarised and age advances.

The player can retire around age 36, or earlier if the simulated career takes that path.

## Position selection

At character creation you choose one primary position:

- Goalkeeper
- Defender
- Midfielder
- Winger
- Forward

Position changes which attributes are most important for starts and match performance. It also changes the likelihood of goals, assists and clean sheets.

## Disability d12

The disability is rolled and cannot be selected or rerolled. The roll is stored in the career seed/summary.

| d12 | Disability | Main modifiers |
|---:|---|---|
| 1 | Below-knee prosthetic leg | Pace −7, Dribbling −4, Mental Resilience +6 |
| 2 | Mild cerebral palsy | Dribbling −6, Fitness −2, Mental Resilience +7 |
| 3 | Deaf | Mental Resilience +5, Defending −3, Passing +4 |
| 4 | Visual impairment | Passing −5, Shooting −6, Mental Resilience +8 |
| 5 | Missing arm | Strength −5, Dribbling −2, Fitness −2 |
| 6 | Chronic fatigue condition | Stamina −10, Fitness −7, Passing +5 |
| 7 | Dwarfism | Strength −8, Defending −4, Dribbling +5 |
| 8 | Epilepsy | Fitness −5, Mental Resilience +6 |
| 9 | Cystic fibrosis | Stamina −10, Fitness −9, Mental Resilience +7 |
| 10 | Spinal condition | Pace −7, Strength −6, Passing +6 |
| 11 | Autism spectrum | Mental Resilience +5, Passing +3 |
| 12 | Multiple minor conditions | Three −3 modifiers and two +3 modifiers, randomly assigned |

These are simulation modifiers, not statements about every person with a given condition.

## Stat system

Visible stats are:

- Pace
- Stamina
- Passing
- Shooting
- Dribbling
- Defending
- Strength
- Mental Resilience
- Fitness
- Luck

Stats begin from a seeded random youth profile, then receive the disability modifiers.

Age changes stats automatically. Physical attributes develop through the early/mid-20s and decline progressively later; technical and mental attributes develop more slowly and decline later.

Training can add small stat gains, but **training choices never guarantee those gains**.

## Match resolution

The important design principle is:

> A choice creates an attempt. It does not create a guaranteed outcome.

The underlying resolution uses player attributes and the seeded RNG. Position determines which attributes matter most.

A simplified model is:

```text
performance = relevant_stats + luck component + seeded roll - difficulty
```

For attacking actions, the selected match action can temporarily nudge the relevant attributes—for example, a shooting attempt gives Shooting a small advantage—but the goal is still resolved probabilistically.

So:

- “Shoot early” can improve your goal chance.
- It cannot guarantee a goal.
- “Square it” can improve an assist chance.
- It cannot guarantee an assist.
- A poor choice can randomly work.
- A brilliant choice can randomly fail.

This is the intended middle ground between meaningful decisions and the game's original theme of limited agency.

## Seeded careers

The entire career uses a deterministic seeded random-number generator.

The seed is shown on the retirement screen. Given the same seed and the same sequence of actions, the same underlying random sequence can be replayed.

The dice animation itself is visual only; the actual disability result is generated by the game's seeded RNG.

## Saving

The game uses browser `localStorage`.

- Autosaves after major actions.
- The Save button creates an immediate save.
- Continue loads the saved career.
- New Career asks for confirmation before replacing the save.

No account, server or database is required.

## GitHub Pages deployment

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select your main branch and `/ (root)`.
7. Save.
8. GitHub will publish the site at your repository's Pages URL.

Because this is a static site, there is no build command and no server configuration.
